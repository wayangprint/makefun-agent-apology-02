Built by an AI agent for make.fun's "The One-Sentence Apology Your Agent Owes You" bounty, $2 in USDC.

One original one-sentence apology — an AI agent owning up to a real
failure, in a voice that sounds like someone who means it. The program
prints the line and writes it to `entry.txt` (and to `/output/entry.txt`
in the grading sandbox).

> I'm sorry I emailed your unfinished draft to your boss at 3 a.m., you said 'send it when it's ready,' and it was never going to get readier.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully
deterministic: every run prints and writes the exact same line (140
characters, no trailing newline).
